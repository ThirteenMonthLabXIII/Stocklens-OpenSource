# 开源价值与模块导览

项目适合供桌面工具开发者、数据工程学习者及研究者参考。它的分享价值主要在业务流程、数据边界和可验证实现；免费源不稳定会削弱实际使用体验，不能据此宣传稳定选股服务或策略收益。

## 推荐阅读顺序

| 想学习的内容 | 首先阅读 | 反馈入口 |
| --- | --- | --- |
| 可解释候选筛选 | `stock_tool/core/universe_policy.py`、`selection_policy.py`、`priority_policy.py`、`missing_data_policy.py` | `tools/demo_offline.py`、`tools/test_phase0_5_selection_policy.py` |
| 确定性筛选与运行留痕 | `screener_engine.py`、`screening_workflow.py` | `tools/test_phase1_candidate_layer.py` |
| 数据可获得时间与快照 | `data_snapshot.py`、`factor_store.py` | `docs/数据快照契约.md` 与快照回归 |
| AI 的证据约束 | `evidence_contracts.py` 与阶段2至5文档 | `tools/test_phase2_evidence_package.py`、`tools/test_phase4_multi_agent.py` |
| 观察与评价 | `performance_loop.py`、`evaluation_stores.py` | `tools/test_performance_loop.py`、`tools/test_phase7_evaluation.py` |
| 桌面交互和后台任务 | `stock_tool/ui/qt_workbench.py`、`qt_theme.py` | Qt smoke 与交互回归；依赖 PySide6 |
| PIT 与执行语义 | `research/pit_join.py`、`execution_ledger.py`、`event_backtest.py` | 对应 `research/test_*.py` |

前四行 core 文件均位于 `stock_tool/core/`。先跑合成输入演示，再阅读单个模块与回归，比先获取全市场历史数据更容易了解设计。

## 值得继续改进的地方

优先支持明确授权的用户自带数据导入、小规模按需研究、数据适配与增量存储，并用实际数据量和耗时验证效果。长期在线数据服务需要明确来源、成本与维护投入。新服务器本身不能保证免费接口不封禁。

`qt_workbench.py` 等模块规模较大，历史商业发布流程也较复杂，初次阅读有成本。本次准备没有为开源顺手重构；可以围绕具体功能逐步学习和改进。

## 价值判断的限度

离线回归可以支持逻辑约束与工程参考价值，不能证明在线功能随时可用、研究数据完整、策略盈利或会有人持续贡献。源码分享也不要求作者承诺长期维护。介绍项目时明确这些边界，能让读者判断是否适合自己的用途。
