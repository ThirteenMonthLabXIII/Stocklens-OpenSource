# 源码范围与验证说明

本次以 MIT 许可证分享研究与复盘工具的源码，版权署名为十三月。作者已确认附带 Logo 与 SVG 可随源码公开，字体保留 OFL 许可。公开源码不等于商业安装包转正，也不解决免费行情源的可用性。

## 导出独立候选

```powershell
python -X utf8 tools/prepare_open_source.py --output release/open_source_20261006/Stocklens
```

导出器读取当前工作文件，按源码目录、扩展名与文档白名单复制到全新的目录。它不依赖 Git，不复制 `.git` 历史、不覆盖已有输出、不执行商业构建、不提交或推送。目录已存在时选择新的候选名。

原目录的 `.git` 文件指向已不存在的原工作树管理目录。本次采用独立源码快照发布，不携带原私有仓库的旧历史。

候选排除本地数据目录、所有数据库及旁路文件、缓存、研究数据与结果、验收报告、交接记录、私钥、运行日志、构建产物、安装器及 ZIP。公开规则配置保留。5 MiB 以上源码文件和允许目录中的符号链接/目录联接会拒绝导出。

公开候选使用 `docs/open_source/` 中的首页、贡献说明、Issue/PR 模板和离线 CI。旧商业流程的资料只作为开发历史保留，当前首页优先说明真实限制。
