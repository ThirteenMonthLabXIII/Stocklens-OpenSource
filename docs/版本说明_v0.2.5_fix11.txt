A股选股仪 增强版 v0.2.5_fix11

一、本版本重点

1. 新增 AI费用透明提示。
2. AI解读、AI排序、AI观察结果中会显示预计输入/输出 token。
3. 显示按公开 API 单价估算的美元费用和约人民币费用。
4. 如果模型接口返回 usage，会显示实际输入/输出 token 和按实际用量估算的费用。
5. 设置页新增当前模型的计费参考说明。

二、估算规则

1. 输入 token 由提示词长度粗略估算。
2. 输出 token 按本次调用设置的 max_tokens 作为上限估算。
3. 实际扣费以 DeepSeek/OpenAI 平台账单为准。
4. 人民币金额按 1 USD 约 7.2 CNY 估算，仅供用户理解成本量级。
