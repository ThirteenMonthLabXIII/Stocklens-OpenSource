# 阶段 0：产品和数据契约冻结

本阶段只冻结语言、身份和边界，不接入五 Agent 编排，也不改变旧数据库的读取方式。

## 1. 三份 v1 契约

实现位置：`stock_tool/core/evidence_contracts.py`。

### Fact v1

每条事实必须包含：

```text
fact_id
code
field_name
value
unit
source
source_version
effective_at
available_at
snapshot_id
quality_status
raw_hash
```

`Fact.from_snapshot_fact()` 是旧快照事实行到新契约的只读适配器，不修改现有 `data_snapshot_facts` 表。`available_at`、`snapshot_id` 和 `raw_hash` 共同用于回放边界；事实质量只允许 `verified`、`partial`、`unverified`、`blocked`。

### CandidateLens v1

每个 Lens 必须包含：

```text
lens_id
lens_version
name
purpose
required_fields
hard_filters
exclusion_rules
evidence_fields
observation_conditions
```

初始只冻结三个 Lens：`quality_research`、`trend_observation`、`event_verification`。Lens 是候选观察视角，不拥有候选状态，也不允许把缺失事实转换成零分。

### AgentResult v1

正式 Agent 结果必须包含：

```text
agent_id
agent_version
run_id
snapshot_id
prompt_version
model_version
status
coverage
claims
counter_claims
missing_evidence
risk_flags
unresolved_questions
diagnostics
cost_note
```

`status` 统一为 `ok`、`degraded`、`failed`、`skipped`。claim 类型只能表达 `supports_lens`、`opposes_lens`、`context`、`insufficient` 或 `no_observed_counter_evidence`。正式结果只负责整理事实、缺口和冲突，不能改变候选集合或候选状态。

## 2. 候选状态

确定性候选状态统一为：

```text
eligible
candidate
watch
insufficient
conflicted
excluded
stale
invalidated
closed
```

Agent 不得直接写入、升级、删除、排序或评分候选。后续阶段的状态转换必须由本地规则和人工动作完成。

## 3. 正式 Agent 禁止字段

`AgentResult` 递归拒绝以下交易或排序字段：

```text
buy / sell / can_buy
target_price / entry_price / stop_price / fail_price
expected_return / return_rate
position / position_hint / weight / allocation
rank / rank_order / score / ai_score
confidence / final_rating / stance
bullish / bearish / neutral
```

正式输出也拒绝买入、卖出、目标价、止损价、仓位、收益率以及 bullish/bearish/neutral 等结果性表述。旧接口仍可在兼容边界内读取，但不能通过 `AgentResult` 校验。

## 4. 旧字段兼容规则

- `professional_formula.py` 保留为 legacy 兼容实现，不删除旧公式历史记录。
- `trade_ai.py` 保留旧接口和旧字段读取能力，但不允许进入正式 Agent 或正式候选流程。
- 旧 `formula_version` 读取时通过 `selection_policy_version = legacy_formula.<version>` 建立明确身份；新正式流程使用 `selection_policy_version` 或 `lens_version`。
- `local_score`、`ai_score`、`rank`、交易价位和 `confidence` 只标记为 `legacy.*`，不映射为正式 Agent 字段。
- 旧数据库继续通过现有迁移和读取层访问；阶段0不重建、不清空、不回写旧交易字段。

## 5. Qt 和产品口径

正式 Qt 流程的 AI 文案使用“研究旁路”“证据整理”“数据缺口”和“冲突识别”，不称为预测器、最终决策者或买卖建议。AI 失败时保留本地确定性结果；AI Key、模型版本和费用仍需显式展示。
