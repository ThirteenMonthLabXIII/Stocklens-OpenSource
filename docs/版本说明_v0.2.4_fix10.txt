A股选股仪 增强版 v0.2.4_fix10

一、本版本重点

1. 首次启动强制选择数据存储文件夹。
2. 自选股、缓存、抓取日志、观察/持仓任务、设置和 API Key 都保存到用户选择的数据文件夹。
3. 设置页新增当前数据目录显示。
4. 设置页新增“打开数据目录”按钮。
5. 设置页新增“重新选择数据目录”按钮，可把当前数据复制到新的文件夹。
6. 商业版交付包不包含 data_location.txt、SQLite 数据库或任何个人信息。

二、设计目的

1. 避免默认长期占用 C 盘用户目录。
2. 避免售出商品包时携带开发者自己的自选股、缓存、API Key 等个人数据。
3. 方便用户把个人数据统一放到 D 盘专用文件夹，例如 D:\StockLensData。
4. 用户后续可以迁移数据目录。

三、注意事项

API Key 会按用户要求跟随数据目录保存，因此用户需要妥善保管自己的数据文件夹。
如果用户把数据文件夹发给别人，里面可能包含个人设置、缓存、自选股和 API Key。

四、保留内容

1. fix6 行情稳定性修复全部保留。
2. fix7 AI观察增强全部保留。
3. fix8 UI 美化全部保留。
4. fix9 品牌水印全部保留。

五、验证记录

1. Python 编译检查通过。
2. PyInstaller build.spec 打包通过。
