A股选股仪 增强版 v0.2.3_fix9

一、本版本重点

1. API Key 改为优先保存到 Windows 凭据管理器。
2. SQLite 本地数据库不再明文保存 ai_api_key。
3. 启动时会自动迁移旧数据库中的 ai_api_key 到 Windows 凭据管理器，并删除旧设置项。
4. 如果极少数电脑无法使用 Windows 凭据管理器，软件会退回本地数据库兜底，并在设置页显示当前存储方式。
5. 顶部新增轻水印：“十三月年二 出品 · 仅限授权用户使用”。
6. 激活后水印会显示授权码尾号，方便追踪测试版或销售版来源。

二、水印策略

本版本采用轻量常驻水印，不遮挡按钮和表格，不影响用户正常使用。

当前水印目的：

1. 提升品牌识别。
2. 对截图、录屏和转卖演示形成来源标记。
3. 为后续正式授权系统预留展示位置。

三、保留内容

1. fix6 行情稳定性修复全部保留。
2. fix7 AI观察增强全部保留。
3. fix8 UI 美化全部保留。

四、验证记录

1. Python 编译检查通过。
2. Windows 凭据管理器读写测试通过。
3. PyInstaller build.spec 打包通过。

五、后续建议

1. 正式商业化前增加服务端授权和设备绑定。
2. 针对每个买家生成不同授权码，使水印尾号具备追踪价值。
3. 增加“清空个人数据/出厂重置”功能。
