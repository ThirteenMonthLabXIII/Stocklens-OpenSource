A股选股仪 增强版 v0.2.2_fix8

一、本版本重点

1. 进行第一轮 UI 美化，不更换底层框架，保持打包和运行稳定。
2. 新增顶部产品栏，显示软件名、版本和核心定位。
3. 统一浅色金融工具风格，包括背景、主题色、按钮、标签页、表格和文本区。
4. 表格统一行高、表头样式和斑马纹，提升可读性。
5. 自选股涨跌幅新增颜色和符号：
   - 上涨显示红色和正号，例如 +2.57%。
   - 下跌显示绿色和负号，例如 -2.57%。
   - 平盘显示灰色 0.00%。
6. AI观察和AI解读文本区优化为更适合阅读报告的样式。
7. 删除、清空等风险操作使用更醒目的按钮文字颜色。

二、保留内容

1. fix6 行情稳定性修复全部保留。
2. fix7 AI观察增强全部保留。
3. 没有引入新的第三方 UI 框架，仍使用 tkinter/ttk。
4. 商业出售版仍然只提供 exe 和用户说明，不暴露源码。

三、验证记录

1. Python 编译检查通过。
2. PyInstaller build.spec 打包通过。

四、后续建议

1. 实测各页面在不同屏幕缩放比例下的显示效果。
2. 根据反馈继续调整配色、行距和信息密度。
3. 后续如果要做更专业的商业版界面，可考虑迁移到 PySide6。
