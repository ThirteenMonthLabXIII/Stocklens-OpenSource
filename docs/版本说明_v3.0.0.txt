Stocklens V3 / A股选股仪 V3

本版本用于公开数据整理、候选股研究、策略复盘和交易观察，不构成投资建议。

修复说明：
- 研究页右侧“基础行情、趋势、均线、动能、机会、风险、数据缺口”情报栏现支持垂直滚动；在较低窗口高度和较窄右栏下，长趋势、指标和值会按可用宽度换行，不再因布局压缩而被文字遮挡或截断。

支持说明：
- 正式支持 Windows 11 24H2 / 25H2 x64。
- Windows 10 22H2 x64 不在正式支持范围，也不承诺已验证通过；若兼容性验证未执行或失败，请使用 Windows 11 24H2 / 25H2 x64。

商业包不含源码、数据库、缓存和密钥。首次启动请按提示选择自己的数据目录。

安装包发布链使用内部完整性签名，但当前没有 Windows Authenticode 发布者证书，系统安装提示可能显示“未知发布者”；请仅使用交付方提供并已核对哈希的安装包。

数据源可能延迟、缺失或变化；请以交易所、上市公司公告和正规金融数据服务为准。
