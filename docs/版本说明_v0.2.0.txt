A股选股仪 增强版 v0.2.0

主要更新：

1. 智能筛选器增强
   - 默认扫描数量从 80 提升到 300。
   - 支持设置扫描数量和结果数量。
   - 筛选完成后显示扫描、跳过、失败统计。
   - 允许 PE 缺失，避免好公司因单个字段缺失被直接排除。

2. 新增本地技术画像
   - 计算 MA5 / MA20 / MA60。
   - 计算 RSI14、KDJ-J、ATR14、量比。
   - 给出机会等级、触发价、失效价、目标价。

3. 新增 AI候选股排序
   - 先用本地规则从市场筛出候选股。
   - 再让 AI 对前 30 只候选股二次排序。
   - 输出 AI分、机会等级、动作和简短理由。

4. 数据逻辑修正
   - 财务指标尽量按报告日期取最新行，避免误用旧数据。

注意：

- 本软件仅做数据整理和候选股研究辅助，不构成投资建议。
- AI排序会消耗用户自己的 API Key 额度。
- 数据源来自公开接口，可能存在延迟、缺失或接口变化。
