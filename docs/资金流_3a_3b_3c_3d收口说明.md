# 资金流 3a/3b/3c/3d 收口说明

本文用于固定当前资金流能力边界，避免后续把 Tushare 增强兜底误解为默认依赖。

## 当前可交付能力

- 智能筛选“主力进场”使用 `DataFetcher.market_money_flow()` 的东方财富批量资金流，口径为 f164 近5日主力净额，筛选前一次批量取数，内存过滤。
- 个股详情、交易观察和本地观察使用逐只历史 `fflow/daykline/get`，用于计算 main_3d、main_5d、main_10d；历史源失败且无缓存时，可降级到腾讯当日资金流，并在 summary 标注“仅当日值”。
- 当前资金流主链路无 Tushare token 依赖，也不消耗 AI token。客户自带 Tushare token 时，可在设置页显式开启资金流增强兜底。

## 3a 结论

`3a PASS：逐只 money_flow 多日窗口离线回归通过。`

封版命令：

```powershell
python -m compileall stock_tool tools
python tools\test_money_flow_window.py
python tools\test_all_blocks.py
```

`tools\check_money_flow_live.py` 保留为人工可选证据脚本；live 300059 对照仅为风险核对。若东方财富限流、网络、代理或公开接口波动导致失败，只记录风险，不阻断 3a PASS。

## 3b 结论

`3b：东财主链路 + Tushare 可选增强兜底。`

- `market_money_flow()` 保持东方财富 f164 为第一优先级。
- akshare、efinance、adata 的全市场资金流与东方财富同源或同链路，不构成免费独立第二源。
- Tushare `moneyflow_dc` 是客户自带 token 的增强兜底源，需要较高积分，默认关闭，不替代免费主链路。
- 仅当用户填写 Tushare Token、打开“东财资金流失败时启用 Tushare 兜底（需 token/积分）”，且东财批量资金流失败、15 分钟新缓存和 1 天内旧缓存都不可用时，才尝试 Tushare。
- Tushare 按 `trade_date` 拉最近 5 个开市交易日的全市场 `moneyflow_dc`，聚合 `ts_code` 的 `net_amount`，并按“万元 * 10000 = 元”对齐现有 f164 口径。
- token 缺失、权限/积分不足、字段缺失、返回行数过少或任一交易日失败，均只作为降级原因；不阻断筛选，不污染 `market_money_flow` 缓存。

`tools\check_moneyflow_dc_feasibility.py` 仍作为可选 live 门槛检查；新增 `tools\check_tushare_moneyflow_fallback.py` 使用生产同款 HTTP 聚合逻辑检查 token/权限/5日聚合。两者都不进入离线完整体测试；无 token 时正常退出，不影响默认免费链路。

## 3c 结论

3c 当前固定“筛选结果解释增强”口径。智能筛选报告 notes 会说明：

- 资金流可用时：主力进场使用东方财富批量资金流，或使用 15 分钟内/1 天内缓存。
- Tushare 兜底命中时：东方财富资金流不可用，已使用 Tushare `moneyflow_dc` 增强兜底。
- 资金流不可用时：东财限流；Tushare 未启用/无权限/无 token，已忽略主力条件。
- 因子快照筛选时：本地快照不含资金流，实时智能筛选可使用公开批量资金流。

## 3d 离线收口

3d 证明当前免费链路可交付，不引入 live 必过项。离线完整体验收命令：

```powershell
python -m compileall stock_tool tools
python tools\test_money_flow_window.py
python tools\check_moneyflow_dc_feasibility.py
python tools\check_tushare_moneyflow_fallback.py
python tools\test_all_blocks.py
```

其中两个 `check_*moneyflow*` 脚本都是可选 live 门槛说明，不是当前功能依赖；无 token 输出成功退出码 0。

## 买家与后续开发边界

本工具用于公开数据整理、候选股研究和复盘辅助，不构成投资建议。资金流数据来自公开源，可能延迟、缺失、被限流或临时变化；软件会展示降级和风险提示，但不承诺实时完整性。

Tushare `moneyflow_dc` 是客户自带 token 的增强兜底源；默认不启用，不影响免费链路。启用后仅在东方财富批量资金流不可用且无可用缓存时尝试，可能消耗 Tushare 权限/积分。
