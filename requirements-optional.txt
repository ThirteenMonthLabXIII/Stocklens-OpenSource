# 可选第三方资金流兜底源：核心运行、商业包默认依赖不需要安装。
# 仅在东方财富网关重试耗尽后才尝试导入，用于降低用户可见失败率。
#
# 诚实提示：A 股资金流日线历史本质是“东财独有”。下面两个库的资金流接口
#   - adata.get_capital_flow 默认走 East（东财）
#   - efinance.stock.get_history_bill 走 push2his（东财）
# 都与本机访问东财同一 IP；当本机 IP 被东财限流/封禁时它们会一起失败，
# 因此对“IP 级限流”场景帮助有限（代码里会在该场景跳过 efinance）。
# 真正与东财不同 IP 的独立兜底是内置直连腾讯当日资金流（无需 pip 安装），
# 它只提供当日主力净流入、无日线历史窗口。
